# Project documentation

Use this folder for reviewed design artifacts as the project progresses:

- `requirements.md` — confirmed MVP scope, roles, and acceptance criteria
- `architecture.md` — component and deployment diagrams
- `data-model.md` — ER diagram, entities, indexes, and versioning rules
- `api-contract.md` — endpoint contracts
- `rag-design.md` — ingestion, chunking, retrieval, metadata filters, and citation format
- `workflow-design.md` — LangGraph state, nodes, transitions, and human interrupts
- `security-and-risk.md` — threat model, privacy, guardrails, and demo limitations
- `evaluation.md` — test corpus, expected evidence, and quality metrics

Create these documents as the corresponding design decisions are agreed. The authoritative stage plan currently lives in the repository-root `plan.md`.
